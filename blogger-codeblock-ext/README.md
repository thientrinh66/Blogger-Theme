# Blogger Code Block (Chrome)

Nút `</>` góc phải khi soạn bài trên Blogger → chọn ngôn ngữ → dán code → **Chèn** hoặc **Copy HTML**.

## Cài đặt

1. Mở Chrome → `chrome://extensions`
2. Bật **Developer mode**
3. **Load unpacked** → chọn thư mục `blogger-codeblock-ext`
4. Mở trang soạn bài Blogger

## Dùng

1. Bấm nút xanh `</>`
2. Chọn ngôn ngữ (JSON, PowerShell, HTML…)
3. Dán code → **Chèn**
4. Nếu không chèn được: bấm **Copy HTML**, chuyển editor sang **HTML**, Ctrl+V

HTML tạo ra đúng format Probha (`pre` + `code class="language-..."`).
