# Power App Icons

Browse Fluent / Lucide / Bootstrap / Material / Tabler icons → click → copy Power Apps YAML.

## GitHub Pages

1. Create a repo (e.g. `powerapp-icons`).
2. Upload these files to the repo root (or `/docs`):
   - `index.html`
   - `styles.css`
   - `embed.js`
3. Settings → Pages → Deploy from branch `main` / root (or `/docs`).
4. Open `https://<user>.github.io/powerapp-icons/`.

Local: open `index.html` or use any static server.

## Features

- Libraries: Fluent 2, Lucide, Bootstrap, Material, Material Symbols, Tabler
- Empty search = browse all icons in the set (paginated)
- Search loads up to 999 matches, then client-side pages
- Click icon → clipboard YAML for Power Apps `Image` control
- Alias icons resolved (no empty cells)
- Always light UI
